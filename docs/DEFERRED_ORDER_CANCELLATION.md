# 보류: 주문 취소·환불 검증

사용자가 "주문취소 다시 띄워줘" 또는 "추문취소 다시 띄워줘"라고 요청하면
아래 내용을 다시 설명하고 현재 코드를 재확인한다. 이 메모는 예약 알림이나
자동 실행 지시가 아니며, 재개 요청 전에는 취소 기능을 수정하거나 주문을 변경하지 않는다.

- 현재 고객 주문 화면에는 실제 주문 취소 버튼이 연결되어 있지 않다.
- `StoreController.cancelOrder`와 API 저장소 함수는 있지만 화면에서 호출하지 않는다.
- 서버 `POST /orders/{order_id}/cancel`은 미결제 `PENDING_PAYMENT` 주문만 허용한다.
- 결제 완료 `PAID` 주문은 이 API로 취소할 수 없다. 환불 경로가 별도로 필요하다.
- 기존 환불 API는 직원 `REFUND_MANAGE` 권한이 필요하다.
- 결제 후 취소/환불에서는 재고 예약, 출고 상태, 쿠폰/포인트 복원도 함께 검증해야 한다.
- 주문 생성·저장·재로그인 조회는 확인했다. 주문 취소·환불의 고객 UI 및
  실제 앱 끝까지의 흐름 검증은 아직 완료하지 않았다.
- 고객 문의 등록 → 직원 답변 → 고객 답변 확인 테스트는 별도 기능의 검증이며,
  주문 취소를 대체하지 않는다.

현재 우선 작업은 고객 앱 카카오·네이버 로그인이다.
