## 통합한 내용

- 현재 SHOEPICK 테마, 폰트, 주문·배송·상품 카드, Drawer, 검색 및 탭바 디자인을 유지했습니다.
- 장바구니·상세의 실제 상품 옵션 조회, 245 사이즈 예외 수정, 기획전 빈 목록 처리와 찜 제거 애니메이션을 유지했습니다.
- 소셜 로그인, 로그인 복원, UID별 SQLite 장바구니·찜·최근 본 상품 분리 기능을 추가했습니다.
- 계정 전환 또는 저장소 미준비 중에는 쇼핑 데이터를 변경하거나 이전 계정의 결과를 반영하지 않도록 통합했습니다.
- 회원가입의 이름 입력과 년·월·일 드롭다운을 유지했습니다.
- 실제 Firebase 회원가입에는 SMS 인증을 연결하고, 중복된 일반 전화번호 입력·날짜 선택기를 제거했습니다.
- SMS 가입 경로도 입력한 이름을 Firebase 표시 이름과 MySQL 고객 프로필에 전달합니다.
- 실제 SMS 가입의 생년월일은 선택이며 일부만 입력한 날짜, 미래 날짜와 윤년을 검증합니다.
- 로그인 시 기존 전화번호·생년월일을 덮어쓰지 않는 처리와 ensureOnly 프로필 연결을 함께 유지했습니다.
- 마이페이지는 이름을 우선 표시하고, 이름이 없는 이메일 회원만 이메일 앞부분을 표시합니다.
- 소셜 로그인 공급자 배지와 디버그 Firestore 접근 검사 기능을 추가했습니다.
- 현재 직원 가입·주문·재고·조달 API와 새 고객 인증·문의 API를 함께 유지했습니다.
- 주문 오류와 리뷰 조회 오류를 별도로 표시합니다.
- 긴 상품명이 구매 옵션 창을 넘치던 배치를 수정했습니다.
- 새 로그인 대기 화면과 휴대폰 동의 문구에도 SHOEPICK 표시 이름을 적용했습니다.

## 실행 전 필요한 설정

1. 다른 환경에서 적용하지 않았다면 MySQL 마이그레이션 025, 026을 확인 후 적용합니다.
   이 병합 작업에서 실제 MySQL 스키마나 데이터를 변경하지 않았습니다.
   기존 기본 스키마·시드 파일은 재실행하지 않습니다.
2. 카카오·네이버 설정은 [소셜 로그인 안내](SOCIAL_LOGIN_SETUP.md)를 참고합니다.
   개인 키 설정 파일 `social-login.local.json`과 백엔드 `.env`는 Git에 올리지 않습니다.
3. SMS 설정은 [휴대폰 등록 안내](PHONE_ENROLLMENT.md)를 참고합니다.
   Firebase 전화번호 로그인, Android 인증서와 실제 기기 인증을 별도로 확인합니다.
4. FastAPI는 새 라우터를 읽도록 재시작하고 Flutter는 Hot Restart(R)합니다.
